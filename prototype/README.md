# تجربة نموذج وينك الأول

هذا نموذج تفاعلي عربي لمراجعة التصميم والرحلات قبل تنفيذ تطبيق Flutter. جميع الحسابات والأسماء والحالات والمعاملات فيه اصطناعية. لا ينشئ حسابًا ولا يجري دفعًا ولا يتصل بقاعدة بيانات المشروع.

## فتح النموذج

الطريقة الأبسط بعد تجهيز الحزمة هي فتح `releases/wainak-preview.html` في متصفح حديث. يجمع هذا الملف الواجهة والخط والكود، ويعمل دون اتصال. يمكن أيضًا فك `releases/wainak-prototype.zip` وفتح `wainak-prototype/index.html` مع إبقاء الملفات المجاورة في أماكنها.

لا تدخل معلوماتك الشخصية في النموذج. الاختيارات تخص ملفات تجريبية، وتبقى حالة التجربة في ذاكرة الصفحة فقط؛ إعادة تحميل الصفحة تعيد الحالة. لا تحفظ المحادثات ولا ترسل بلاغات فعلية، وأي شراء أو قبول من الشريك هو محاكاة معلنة.

## ما تراجعه

1. اختيار المسار والتسجيل التجريبي.
2. عرض مرشح وطلب التعارف والقبول والدفع المحاكى.
3. مساحة العلاقة والإجابة على بطاقة نقاش وحالة الإرسال.
4. الحصرية وطلب الصورة، مع الفصل بين الموافقة والشراء والكشف.
5. المساحة الزوجية ومراحل الحياة وفصل مساحة كل زوجة والعدد المقر به.

تتضمن التجربة حالات بديلة للانتظار والرفض والخطأ. استخدم أسماء الأزرار والتنقل الدلالي؛ لا تحتاج إلى تفسير لون وحده. في الكمبيوتر يمكن استخدام Tab وShift+Tab للتنقل، وEnter أو المسافة لتشغيل الأزرار بحسب نوعها.

الهوية المقترحة خلفية عاجية وبطاقات بيضاء ونصوص وأزرار توتية داكنة، مع لمسات وردية زخرفية. يظل هذا اتجاهًا أوليًا ينتظر مراجعة المستخدمين، وليس ادعاء باختبار تفضيلات المستخدمات.

## حدود الاختبار

هذا النموذج لا يختبر تشفير المراسلة أو وصول الرسائل بين هاتفين أو StoreKit أو Play Billing أو ضمان العمر أو حساب عدد الزوجات في الواقع. الأهلية والموافقات محاكاة لشرح القواعد؛ التنفيذ الفعلي يحتاج تحقق الخادم.

الفحوص الآلية للمتصفح والوصول تساند التجربة اليدوية. لا تعني نجاح VoiceOver وTalkBack على أجهزة فعلية ما لم توجد نتيجة مستقلة لذلك. تراجع نتائج هذه الدفعة في [تقرير التنفيذ](../docs/reviews/iteration-01.md) عند اكتماله.

## أوامر المراجعة للمطور

من مجلد `prototype`، تثبت اعتماديات الاختبار من القفل ثم تشغلها. لا يحتاج الملف المستقل هذه الاعتماديات عند المستخدم:

```bash
npm ci --ignore-scripts
```

```bash
npm test
```

تستخدم الاختبارات Chrome المثبت محليًا. لتجهيز النسخة المستقلة والأرشيف وبصماتهما:

```bash
npm run package
```

ملفات الخط وترخيصه ضمن `dist/assets`، وتحفظ إشعارات الترخيص أيضًا في نسخة HTML المستقلة. لا تشمل الحزمة أسرار التشغيل أو قاعدة البيانات أو النسخ الاحتياطية أو أدوات الاختبار.
