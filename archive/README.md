# الأرشيف المشفر الاصطناعي

تجربة Go لتصدير واستيراد تاريخ اصطناعي محدد الصيغة باستخدام age/X25519، مع تحقق من المدخلات وحدود الحجم. هذه المكتبة ليست نظام محادثة أو مخزن بيانات إنتاجية. الحالة المجمعة في [STATUS.md](../docs/STATUS.md).

ملفات المصدر الأساسية `archive.go` والاختبارات `archive_test.go` و`interop_test.go`. تحفظ التبعيات في `go.mod` و`go.sum` وتراخيصها في `notices`؛ لا تغير النسخ أو التراخيص لإخفاء إخفاق فحص.

بعد تجهيز Go1.27.3 ووحدات القفل، من هذا المجلد:

```bash
GOTOOLCHAIN=local go test ./...
```

توجد اختبارات مستقلة إضافية تحت `qa/phase5_archive`. أدوات التشغيل القديمة التي افترضت مسارات خاصة بالمضيف لم تعد مسار التنفيذ الحالي؛ تستعمل وصفة CI المجمعة والاختبارات المحمولة.

لا تثبت الاختبارات الحالية حفظ مفاتيح هاتف أو منتقي ملفات أو نسخة iCloud/Drive أو استعادة محادثة حقيقية. نتائج الأمن السابقة مرتبطة بالتبعيات التي فحصتها؛ عند تغير graph تعاد الفحوص المناسبة. [المواصفات والحدود](../docs/reviews/phase5-archive-qa-results.md).
