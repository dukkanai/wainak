# وينك

وينك، بالاسم اللاتيني `wainak`، تطبيق عربي قيد التطوير لنظامي iOS وAndroid، يساعد المسلمين البالغين على البحث عن شريك للزواج والاستعداد للحياة المشتركة ومواصلة الحوار خلال الخطبة والزواج.

المستودع العام: [dukkanai/wainak](https://github.com/dukkanai/wainak). نتائج الاختبارات: [GitHub Actions](https://github.com/dukkanai/wainak/actions/workflows/ci.yml).

- [سياسة المستودع وCI](docs/repository-and-ci.md): الفروع والحماية وحدود النشر.

## ما يحتويه المصدر

- `apps/mobile`: Flutter بالعربية وRTL، ومسارات تطوير صريحة للهوية والمطابقة ومعاينة البطاقات والأرشيف الأصلي.
- `backend` و`contracts`: قواعد الحسابات والمطابقة والعلاقات، وDjango/allauth للاختبارات المعزولة، وعقود API.
- `archive` و`archivebridge`: تجربة أرشيف مشفر وجسر أصلي محدود ببيانات اصطناعية؛ ليست مراسلة بين هاتفين.
- `prototype`: نموذج HTML مستقل لمراجعة التصميم، منفصل عن تطبيق الهاتف.
- `ops`: أدوات PostgreSQL والنسخ والاستعادة المعزولة.
- `ci` و`qa`: ضوابط البناء واختبارات إضافية مستقلة.

هذه نسخة تطوير، وليست خدمة عامة أو إصدار متجر. المصادقة الحالية تستخدم بريدًا اصطناعيًا وواجهات محلية. قبول طلب التعارف لا يفتح مراسلة أو شراء حقيقيين. لا ترسل بيانات شخصية إلى أوضاع التجربة.

## الوثائق والأدلة

تصف المواصفات المنتج المطلوب؛ ويصف [ملف الحالة](docs/STATUS.md) ما تحقق منه فقط. تحفظ [تقارير المراحل والمراجعات](docs/history/README.md) دليلًا تاريخيًا مرتبطًا بمصدره وتاريخه، ولا تُقرأ كحالة حية للنسخة الحالية.

أسرار التشغيل والنسخ والمخرجات المولدة خارج Git. يحتفظ [سجل التنظيف](docs/history/cleanup-20261027.md) بنطاق جمع الفروع وحفظ الأدلة وإزالة المخرجات المتروكة.
