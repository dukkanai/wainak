# وينك

وينك، بالاسم اللاتيني `wainak`، مشروع تطبيق Flutter لنظامي iOS وAndroid يساعد المسلمين البالغين على البحث عن شريك للزواج، والاستعداد للحياة المشتركة، ومواصلة الحوار خلال الخطبة والزواج.

المستودع العام: [dukkanai/wainak](https://github.com/dukkanai/wainak). نتائج الفحوص التلقائية: [GitHub Actions — CI](https://github.com/dukkanai/wainak/actions/workflows/ci.yml).

## حالة المشروع

المواصفات ونموذج المتصفح الأصلي محفوظان. توجد الآن شريحة تطوير Flutter ومسار API للملف والمطابقة وطلبات التعارف وحوار البطاقات والموافقات والحظر والبلاغات، إضافةً إلى أساس حسابات وجلسات Django/allauth وحذف الحساب. تختبر هذه الشريحة بريدًا وهميًا وحسابات `@example.invalid` وقواعد PostgreSQL مؤقتة معزولة؛ ليست خدمة منشورة أو مصادقة إنتاجية. الدفع والمراسلة المشفرة والبريد الحقيقي وبناء الأجهزة والمتاجر ما زالت خارج هذا الإنجاز.

- [أساس الخادم وحدوده](backend/IDENTITY.md).
- [واجهة الحسابات الأصلية وحدودها](apps/mobile/IDENTITY.md).
- [خطة تكامل النسخة نفسها وبوابات الدمج المحلي](docs/phase2-integration.md).

نتائج فروع منفصلة لا تكفي لقبول النسخة المجمعة؛ يربط تقرير QA المستقل كل قبول بمعرّف commit محدد. الدمج المحلي لا يعني رفع GitHub أو نشر خدمة أو ترحيل قاعدة التشغيل.

فحص التشغيل المحلي:

```bash
python3 ops/manage.py status
```

تظل [المسودة الأصلية](docs/draft.md) محفوظة للتاريخ. عند التعارض، تكون الأولوية للقرارات الأحدث المبيّنة في وثائق المواصفات. أسرار التشغيل والنسخ المحلية خارج ملفات المصدر، ولا يجوز رفعها مع الكود.
