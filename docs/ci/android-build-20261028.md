## البيئة وإعادة البناء

استخدم البناء Flutter 3.47.8 وDart 3.13.7 وTemurin JDK 21.0.13 وGradle 9.3.1 المحدد ببصمة wrapper، وAndroid SDK 36 وbuild-tools 36.0.0 وNDK 30.0.16248370. لم يتغير `pubspec.lock` ولم تستخدم نسخة AAR التاريخية.

في نسخة مصدر منفصلة، اضبط `JAVA_HOME` و`ANDROID_HOME` و`ANDROID_SDK_ROOT` للأدوات المذكورة، و`PUB_CACHE` و`GRADLE_USER_HOME` لمجلدات البناء. نفذ من `apps/mobile`:

```bash
flutter pub get --enforce-lockfile
```

```bash
flutter build apk --debug --no-pub --target-platform android-arm64 --dart-define=WAINAK_DEV_MODE=true --dart-define=WAINAK_REPOSITORY=fake
```

الناتج `build/app/outputs/flutter-apk/app-debug.apk` غير موقع وفق إعدادات المشروع. استخدم تزامنًا واحدًا؛ طبقت المحاولة مهلة 30 دقيقة وحدًا أدنى 4 GiB لمساحة القرص الحرة. اكتمل أمر البناء خلال نحو 292 ثانية. لا يضمن ذلك زمنًا مماثلًا أو إعادة إنتاج البايتات نفسها.

## الحدود والخطوة التالية

الوضع `fake` يعرض بيانات اصطناعية محلية. لا يثبت البناء الدخول إلى خدمة حقيقية أو المراسلة أو الدفع، ولا يتضمن محرك الأرشيف Go/AAR؛ ينطبق عليه مسار المحرك غير المتاح. يلزم بناء ذلك المحرك من سياسة التبعيات الحالية والتحقق منه بصورة مستقلة.

لم يجر تثبيت APK أو تشغيله على جهاز أو محاكي، ولم يجر قبول TalkBack. يلزم هاتف Android arm64 مناسب لاختبار التركيز والتسميات وتكبير النص والعودة وحالات إخفاء التطبيق. النسخة قابلة للتصحيح ومخصصة للبيانات الاصطناعية.

ظهر تحذير Flutter بضرورة الانتقال مستقبلًا إلى Kotlin المدمج، وتحذير اختلاف إصدارات SDK XML. لم يمنعا هذا البناء؛ لا تعني النتيجة قبول ترقية الأدوات أو تجاهل التحذيرات في بناء لاحق.

اجتاز iOS فحوص تجهيز المصدر فقط في هذه الجلسة. لا يوجد Xcode على المضيف الحالي، ولم تتوفر قناة تنفيذ Codemagic. وصفة `ios-unsigned-archive` موجودة في `codemagic.yaml`؛ يلزم تشغيلها على المصدر المحدد وجمع نتيجتها قبل إثبات إصلاح المحاكي. توقيع iOS والتثبيت وVoiceOver مراحل مستقلة لم تنفذ.
