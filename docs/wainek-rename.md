# إعادة التسمية إلى wainek

قرار المستخدم النهائي في 29 أكتوبر 2026: اسم العرض `wainek` حرفيًا، وحزمة الهاتف `com.nextaura.wainek`. العمل محلي على فرع `dev/ios-testflight-internal-20261029`، من أساس `9bb2aa7731911c1b9d16c76ec4f276ec599f7755`، دون تغيير المستودع الخارجي أو موارد التشغيل.

## التغييرات المترابطة

- أسماء العرض في Flutter وAndroid وiOS والويب ونموذج HTML وصفحة حذف الحساب.
- حزمة Dart إلى `wainek_mobile`، وجميع استيراداتها، وأعلام التطوير إلى `WAINEK_*`.
- حزمة Android ومسارات Kotlin إلى `com.nextaura.wainek`، ومعرف iOS واختبارات Runner المناظرة.
- قناة Flutter/Kotlin/Swift إلى `wainek/native_archive_v1` في الأطراف الثلاثة معًا. هذه قناة داخل التطبيق؛ لا تمثل صيغة ملف الأرشيف.
- وحدات Go إلى `wainek.local/...`، مع تحديث الاستيرادات ومسارات replace والاختبارات دون تغيير نسخ الاعتماديات.
- حزم Python إلى `backend/wainek` و`backend/wainek_identity`، وقوالب Django واستيرادات الاختبارات والعقود المرتبطة بها.
- أسماء مخرجات المعاينة الجديدة وواجهات الاختبار المؤقتة. لا يعاد تسمية ملف APK تاريخي أو سجل بناء سابق.

تغيير حزمة Android يجعل أي بناء جديد تطبيقًا مختلفًا عن APK التجريبي القديم عند تثبيته على الجهاز. لا توجد آلية نقل بيانات هاتف تلقائية ضمن هذه الدفعة. سجل Apple القائم احتفظ بمعرفه `6828249128` وفق تأكيد المستخدم، بعد تعديل Bundle ID فيه قبل أول بناء.

## التهجئة القديمة التي تبقى مقصودة

1. `dukkanai/wainak` وروابط GitHub: المستودع الخارجي لم يغيّر اسمه. المسارات المحلية تحت `/home/chatbot/wainak` و`wainak-dev` و`wainak-artifacts` باقية أيضًا.
2. `Codemagic Wainak`: اسم اتصال API الحقيقي الحالي؛ لا يستبدل قبل تأكيد تغيير الواجهة. `WAINAK-IOS-001`: SKU تاريخي ثابت لسجل Apple؛ لا يحذف السجل لتغييره.
3. `wainak-history-v1` و`wainak-synthetic-history-bridge-v1`: معرفا تنسيق الأرشيف والجسر. يبقيهما القارئ والكاتب للمحافظة على توافق v1؛ توجد اختبارات قبول للاسم القديم ورفض تغيير التنسيق بلا إصدار مقصود.
4. `wainak_identity`: اسم تطبيق Django المخزن في قاعدة البيانات، بما فيه `AUTH_USER_MODEL`. اسم حزمة Python أصبح `wainek_identity`، لكن `AppConfig.label` يحتفظ بالاسم القديم حتى لا تعاد تسمية الجداول أو سجل المهاجرات أو نوع المحتوى.
5. `wainak_phase1_dev`: مخطط PostgreSQL القائم. `compose.yaml` وأسماء مشروع Docker والقاعدة `wainak` والمستخدم `wainak_admin` والحاويات والأقراص القائمة لم تتغير. أدوات النسخ والاستعادة وبادئاتها ووصف تشغيلها تبقى متوافقة مع هذه الموارد.
6. البصمات والمسارات في ملفات provenance الأصلية وملفات الأدلة والتقارير التاريخية تبقى حرفية. سجل `ci/wainek-rename-provenance.json` يربط 31 مدخلًا تغير مصدرها أو مسارها ببصمتها السابقة وبصمتها الجديدة؛ الفحص يرفض المصدر المتغير أو البصمة السابقة غير المطابقة أو التحويل خارج المسار المسموح أو الروابط الرمزية. هذه بصمات مصدر، وليست إثبات إعادة بناء القطع الأصلية.
7. أسماء الاختبارات السلبية وبياناتها قد تذكر `Wainak` صراحةً لاختبار التوافق القديم. تقارير `docs/phase*` و`docs/reviews` و`docs/history` و`docs/ci` وملفات QA المؤرخة تصف ما جرى وقتها؛ أوامرها وأسماء حزمها القديمة ليست تعليمات تشغيل النسخة الجديدة. المرجع الحالي هو `docs/DEVELOPMENT.md` وأدلة المكونات المحدثة.

تجد قائمة الملفات التي لا تزال تحتوي التهجئة القديمة في [جرد الاستثناءات](wainek-legacy-inventory.json). لا يحتوي الجرد أسرارًا أو محتويات سجلات تشغيل؛ يسجل أسماء ملفات المصدر وأعداد المطابقات فقط.
