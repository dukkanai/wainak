# جسر الأرشيف الأصلي

واجهة Go محدودة حول الأرشيف الاصطناعي، تستخدم handles وepochs للتحكم في دورة الحياة والإلغاء وحدود الموارد. وجود الجسر لا يثبت تشغيل مكتبة أصلية داخل جهاز مستخدم أو وجود مراسلة مشفرة.

يعتمد `go.mod` على المكتبة المجاورة `../archive`. بعد تجهيز Go1.27.3 والتبعيات المثبتة، من هذا المجلد:

```bash
GOTOOLCHAIN=local go test ./...
```

الفحوص المستقلة موجودة في `qa/phase6_archive_bridge`، ووصفة بناء Android/iOS وضوابطها في [ci/README.md](../ci/README.md). يحتفظ المصدر بقواعد تمنع عرض نجاح مصطنع عندما يغيب artifact أو يختلف عن البصمة المطلوبة.

لا تنقل مفاتيح الأرشيف أو محتواه إلى Dart. لا يوجد في هذه التجربة تخزين جلسة إنتاجية أو منتقي ملفات أو رفع سحابي أو محادثة فعلية؛ مرجع حالة المنتج هو [STATUS.md](../docs/STATUS.md).
